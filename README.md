# TurkceMateryallerBot

VK-бот сообщества **Türkçe Materyaller** для преподавателей турецкого языка,
работающих с уровнями A0-A2.

## Версия 0.1

- главное меню;
- каталог готовых материалов;
- заявки на новые материалы;
- список заявок пользователя;
- подписка и отписка от рассылки;
- генерация упражнений и планов уроков через OpenAI API;
- закрытая точка входа в администраторский раздел;
- SQLite для хранения данных.

## Настройка

1. Установить Python 3.11+.
2. Установить зависимости: `pip install -r requirements.txt`.
3. Создать переменные окружения по примеру `.env.example`.
4. Запустить: `python bot.py`.

Секретные ключи должны храниться только в переменных окружения BotHost. Файл
`.env` исключён из Git и не должен попадать в репозиторий.

На BotHost ключ VK можно указывать только в обязательном поле `Bot Token`:
платформа передаёт его приложению как `BOT_TOKEN`. Переменная
`VK_GROUP_TOKEN` остаётся альтернативой для других сред запуска.
